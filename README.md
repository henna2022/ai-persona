# AI 페르소나 (웹 버전)

카메라로 얼굴을 찾아 눈·코·입을 무작위 도형으로 바꿔 그리고, 표정에 따라 머리 위에 하트/왕관/화남/느낌표를 띄웁니다.
영상 처리는 전부 브라우저 안에서 일어나고 **영상과 얼굴 좌표는 어디에도 전송되지 않습니다.**
밖으로 나가는 것은 완성본이 떴을 때 보내는 "한 번 썼다"는 이용 횟수 한 건뿐입니다.

## 파일
- `index.html` : 앱 전체
- `collect.js` : 이용 횟수 집계 수집기. 완성본이 뜰 때 1회를 보냅니다.
  집계는 https://github.com/henna2022/raim-exhibit-stats 로 모입니다.
  보내는 것은 "한 번 썼다"는 표시뿐이고 얼굴 사진·좌표·기기 번호는 나가지 않습니다.
  집계를 멈추려면 index.html 의 `RaimCollect.init('persona')` 줄을 지우면 됩니다.
- `logo.png` : 완성본 우측 하단에 들어갈 과학관 로고. **이 이름으로 같은 폴더에 넣어주세요.** (없으면 "logo.png 파일을 넣어주세요" 글자가 대신 나옵니다)
- `title.png` : 완성본 상단 가운데에 들어갈 "AI 페르소나" 타이포. 있으면 자동으로 들어가고 없으면 생략됩니다. (검정 선, 흰색 또는 투명 배경, 가로형 권장)
- `examples/` : 전시물 참고 사진. 배포할 때는 올리지 않아도 됩니다.

## 흐름
1. 시작하기 → 카메라 허용
2. 다른 얼굴로 : 누를 때마다 얼굴 틀·눈·눈썹·코·입 조합이 바뀜
3. 촬영하기 : 얼굴을 찾았을 때만 눌리고, 3초 카운트다운 후 촬영. 촬영되면 카메라는 바로 꺼짐
4. 로봇 애니메이션(30초, 길이는 `robotDraw` 안 `TL` 표로 조절) : 위에서 내려다본 컨베이어에서 펜 플로터 엑시드로가 눈·코·입을, 두산 협동로봇이 얼굴 틀과 머리 위 표시를 그린 뒤 종이가 화면을 채우며 완성본으로 이어짐. 움직임 줄이기 설정이면 완성 장면만 잠깐 보여줌
5. 완성본(흰 바탕 검정 선 + 로고) 확인 → 그림 저장(폰은 공유 시트, 그 외는 다운로드) / 다시 하기

애니메이션은 `index.html` 의 `robotDraw` 하나에 다 들어 있고, 그리는 선은 완성본을 그릴 때 쓴 명령을 `recordStrokes` 로 그대로 녹화한 것이라 완성본과 똑같다.

## 표정 → 머리 위 표시
- 웃음 → 하트
- 화남(눈썹 찌푸림) → 화남 표시
- 놀람(입 벌림 + 눈썹 올림) → 느낌표
- 무표정 → 왕관 (하트는 웃을 때만 나오게 고정)

판정 기준값은 `index.html` 상단의 `const T = {...}` 숫자만 바꾸면 됩니다.
주소 뒤에 `?debug` 를 붙이면 현재 표정 수치가 화면에 표시되어 기준값 잡기에 좋습니다.

## 컴퓨터에서 테스트 (카메라 없이)
주소 뒤에 `?img=사진경로` 를 붙이면 카메라 대신 그 사진으로 동작합니다. 예: `index.html?img=examples/test/selfie.jpg`
로컬에서 열 때는 이 폴더에서 아래 명령을 실행한 뒤 `http://localhost:8765` 로 접속합니다.

    python3 -m http.server 8765

## 폰에서 테스트 (배포 전)
카메라는 https 에서만 열리므로, 이 폴더에서 아래를 실행하고 화면에 뜨는 주소를 같은 와이파이의 폰에서 엽니다. 인증서 경고는 "계속"으로 넘기면 됩니다.

    python3 serve.py

## 배포 (QR용 주소 만들기)
카메라는 https 주소에서만 열립니다. 무료 정적 호스팅이면 전부 https 를 줍니다.

GitHub Pages 기준:
1. github.com 가입 → 새 저장소(public) 생성, 이름 예: `ai-persona`
2. `index.html`, `logo.png` 업로드
3. 저장소 Settings → Pages → Branch: main, 폴더: / (root) → Save
4. 몇 분 뒤 `https://<계정이름>.github.io/ai-persona/` 가 열리면 이 주소로 QR 생성
